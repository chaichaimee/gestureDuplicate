## Опис
**gestureDuplicate** — це професійне доповнення для NVDA, створене для підтримки чистоти та ефективності конфігурації вашої програми екранного доступу. Воно допомагає виявляти конфліктуючі жести введення (дублікати гарячих клавіш), керувати користувацькими призначеннями та виконувати глибоке очищення залишкових даних конфігурації від видалених доповнень.

Доповнення надає три основні інструменти обслуговування:
* **Перевірка дублікатів жестів** — виявляє та виводить список усіх дубльованих жестів у всіх контекстах (глобальні, модулі додатків тощо).
* **Керування моїми жестами** — дозволяє переглядати та безпечно видаляти користувацькі жести, призначені доповненням, які більше не встановлені.
* **Очищення конфігурації (nvda.ini)** — ідентифікує та видаляє застарілі розділи конфігурації, що належать видаленим доповненням, які все ще знаходяться у вашому основному файлі *nvda.ini*.

> **Важливо:** З часом видалення доповнень часто залишає «примарні» налаштування в *nvda.ini* та *gestures.ini*. Це може призвести до підвищеного використання пам'яті, конфліктів конфігурації або непередбачуваної поведінки. Цей інструмент гарантує, що ваша NVDA залишиться легкою та стабільною.

## Особливості
* **Виявлення дублікатів жестів:** Сканує всі завантажені призначення (Ядро + Доповнення) для пошуку функціональних конфліктів.
* **Інтелектуальна навігація:** Перехід одним кліком до стандартного діалогу NVDA «Жести введення» з попередньо вибраним відповідним скриптом для негайного виправлення.
* **Очищення примарних жестів:** Спеціально націлене на *gestures.ini* для пошуку записів, пов'язаних з відсутніми доповненнями, відображаючи їх сірим кольором для легкої ідентифікації.
* **Розширене очищення конфігурації:** Сканує основний *nvda.ini* на наявність залишкових розділів від видалених доповнень, дозволяючи безпечно «вичистити» застарілі налаштування.
* **Групові дії:** Підтримує видалення окремих елементів, усіх жестів для конкретного доповнення або повне очищення всіх користувацьких призначень доповнень за один раз.
* **Робочий процес з декількома натисканнями:** Швидке перемикання між інструментами виявлення, керування та очищення за допомогою однієї гарячої клавіші.
* **Орієнтованість на доступність:** Усі діалоги повністю доступні з клавіатури з підтримкою Enter (виконати), Space (переключити), Delete (видалити) та Escape (закрити).

## Як очистити конфігурацію
Щоб підтримувати максимальну продуктивність NVDA, виконайте такі кроки:
1. Відкрийте інструмент **Очищення конфігурації** (Потрійне натискання **Windows+Shift+G**).
2. Перегляньте список розділів, знайдених у вашому *nvda.ini*.
3. Позначте прапорцями доповнення, які ви вже видалили.
4. Натисніть **Видалити вибране**, щоб безпечно видалити ці розділи з вашого файлу конфігурації.

> **Рекомендація:** Запускайте «Керування моїми жестами» та «Очищення конфігурації» після кожного великого видалення доповнень, щоб запобігти потенційним конфліктам і підтримувати порядок у налаштуваннях.
